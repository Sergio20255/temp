# White-Label & Branding

Buyers can customize:
- Site logo
- Site name
- Theme colors
- Email sender settings
- Footer/legal branding

Use `settings` table keys for dynamic branding values. Suggested keys:
- `branding.site_name`
- `branding.logo_path`
- `branding.primary_color`
- `mail.from_name`
- `mail.from_address`
